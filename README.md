# RenderArc
RenderArc is a 3D game engine with a flexiable plugin system.

# Goals
Developing a game in any game engine is a very daunting task, mainly because most game engines are designed around an editor-based workflow. RenderArc takes the opposite approach, focusing on a coder-friendly solution, heavily inspired by Bevy engine. 

# Roadmap
This project is being developed incrementally. As a result, many of the solutions currently used - such as the ECS system, physics system, and other core components - initially rely on external libraries. As development progresses, these systems will gradually be replaced with custom-built implementations developed specifically for the project.
